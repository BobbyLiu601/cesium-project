# ALCY-43 图层与矢量示例 Handoff

## 目标

将后台信息架构调整为 `1、图层`，并在 `1.3、矢量` 下实现参考站 `2.3.1` 到 `2.3.16` 对应的 16 个可交互 Cesium 示例。

## 已确认边界

- 菜单从 `1` 开始，并减少为两级：`1、图层` 下直接显示 `1.1、影像`、`1.2、地形`、`1.3、矢量`，不再展开到单个 Demo。
- 现有功能改名为 `1.1.1、天地图`、`1.2.1、高程`。
- 矢量示例编号为 `1.3.1` 到 `1.3.16`，名称与参考站一致。
- 保留“卡片 + 弹窗”交互，并为每个演示增加可刷新、可分享的独立路由。
- 视觉效果与雷达图保持原名称、原交互，不纳入本次重新编号。
- 16 个演示均使用 Cesium 公开 API 实现真实场景，不使用占位图或空弹窗。
- 矢量卡片封面使用参考站为对应 Demo 提供的 JPG 图片；GeoJSON、SVG 和动画 GIF 使用项目内本地资源。
- 不引入运行时 CDN；GIF 解码优先使用浏览器原生 `ImageDecoder`，不可用时降级为静态帧。
- `1.3.7` 保留 GeoJSON 数据源自带视角；其余演示通过场景包围范围计算初始镜头，并验证主要元素均进入画面。

## 资源说明

- `src/assets/vector-covers/*.jpg` 来自参考站对应 Demo 的封面图。
- `src/assets/vector-demo-hurricane.gif` 为透明动画 GIF，`1.3.16` 使用 `ImageDecoder` 逐帧绘制，不叠加背景阴影。

## 执行清单

1. 建立唯一图层目录，驱动菜单、内容标题、卡片、路由和弹窗。
2. 将菜单收敛为两级导航，同时保留内容分组、移动端抽屉、键盘和焦点恢复。
3. 实现通用演示弹窗、路由深链与旧路由重定向。
4. 实现 `1.3.1` 到 `1.3.16` 的场景构建入口、操作控件、覆盖层和销毁清理。
5. 接入参考站 JPG 封面，补齐本地 GeoJSON、SVG、透明动画 GIF 和测试替身。
6. 运行 `pnpm verify`，提交任务分支并推送。

## 验收

- `1.1.1、天地图` 和 `1.2.1、高程` 从新位置打开原能力。
- 16 个矢量卡片都能打开对应弹窗，直接访问路由可恢复同一演示。
- 关闭弹窗回到卡片并恢复焦点，菜单高亮与地址保持一致。
- 无天地图 Token、外部地形服务不可用或本地素材解码失败时，场景仍可关闭并给出简短失败状态。
- `1.3.8` 不再出现 `Appearance` / `Geometry` 不匹配错误；`1.3.12` 默认显示气泡；`1.3.13` 点击图标可打开并关闭气泡；`1.3.16` 动画持续变化且无背景阴影。
- 单元测试覆盖目录、路由、场景 Cesium 公开对象和清理；Playwright 覆盖桌面、移动端与代表性深链。
