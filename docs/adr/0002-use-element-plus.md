# ADR 0002：使用 Element Plus

- 状态：已接受
- 日期：2026-11-03

## 背景

项目需要搭建一个简单的后台管理界面。用户可以接受自定义 CSS 方案，但明确选择使用 Element Plus。与完全自建组件相比，引入组件库会增加运行时依赖和样式适配成本，但能复用成熟的后台组件并统一后续页面的交互。

## 决策

- 使用 Element Plus 提供菜单、抽屉、卡片等基础组件。
- 采用全局注册并引入完整样式的接入方式；这是用户明确选择的方案，优先降低组件注册和样式引入的维护成本。
- 后台管理壳的布局、Vben 风格和响应式规则仍由项目自行实现，不引入 Vben 依赖。
- Element Plus 通过 pnpm 安装，版本由 `pnpm-lock.yaml` 锁定。

## 影响

- 新增 Element Plus 运行时依赖，并承担全量 JavaScript 与样式带来的包体积成本。
- 后续后台页面应优先复用 Element Plus 的交互模式，避免同一类控件出现多套实现。
- 视觉定制应优先通过主题变量和局部样式完成，避免直接修改组件内部结构。
