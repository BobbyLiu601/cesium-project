## 运行时边界

- 所有封面和 GLB 均随站点本地构建，不热链参考站、SuperMap 或模型 CDN。
- `1.4.2` 的高程瓦片在运行时从 Mars3D 公共地形服务按需加载；该网络服务不可用时回退椭球地形。
- 未复制参考站中许可证不明的模型资源。
- 如替换第三方模型，需要同步更新本文的来源、作者和许可证信息。
